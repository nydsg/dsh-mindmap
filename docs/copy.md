## 3. 长文简介

### 3.1 正式版（npm 说明 / 市场详情页，约 300 字）

**DSH 对话思维导图**是一个把会话轨迹画成图的插件。

它不试图总结对话，只做一件更朴素的事：**让你一眼看到这场会话的形状**。最左侧是一个总标题节点，内容就是这场会话的第一个提问；从它开始，每一轮向右展开一层，卡片上只有你的提问本身——回复不在卡片上，因为它属于右侧面板。

每一轮接在哪里，规则只有两条，顺序就是全部：**提问重新说出了某个更早话题的词，就回到那条分支；否则就接在上一轮后面**。第二条不靠相似度判断，因为对话里下一个问题本来就跟在最后一个回答后面——这是结构，不是猜测。（早先的版本要求相似度达标才算"续接"，结果把真实会话里 9 条追问全部误判成新话题：真实追问都是「那接下来呢」「我在终端执行完了」这样的短指代句，几乎不重复上一轮回复里的名词。）

点一张卡片，右侧列出这一轮全部模块：回复、工具调用、上下文注入，点任一行看原文、关键词权重与前序分析。还可以按关键词过滤——命中的正常显示，未命中的**变暗而不移除**，因为移除会让父节点消失、让结构说谎。

**全部在浏览器本地完成：零网络请求、零模型调用、零构建步骤。**

### 3.2 故事版（博客 / 公众号开头，约 400 字）

我用 DSH 跑长会话时有个反复出现的困扰：翻到第 40 轮，已经想不起前面聊过什么，更看不出**哪几段其实是同一个话题**。轨迹页是按时间排的线性列表，它能告诉你「发生了什么」，但回答不了「这件事讨论到哪一步了」。

所以我写了这个插件。它把会话画成一棵树：总标题在最左边，内容是你会话里的第一个提问；之后每一轮向右展开一层，卡片上只显示你问的那句话。插件会替你判断「这一问是在追问哪一问」，接上去；判断不出来，就另起一条分支。

做这个判断比想象的麻烦。第一版我用余弦相似度，结果发现**没有一条阈值能用**：真正相关的两轮，余弦在 0.29–0.72；而只共享了「插件」「怎么」这类背景词的假匹配，余弦是 0.16–0.20——两段区间叠在一起。后来改成「共享的**信号词**占较小一方的比例」，真连接落在 0.44–1.00、假匹配 ≤0.28，断层才干净，阈值 0.40 就是从这张表上直接读出来的。

图怎么画也踩过坑。第一版连线根本看不见，根因是坐标来自渲染后测量——永远比内容晚一帧，哪次测量没跑到，连线层就是空的。现在列与行全部由算术得出，只有卡片高度还量一次。

**所有分析都在你的浏览器里跑完，没有一次网络请求，也没有调用任何模型。**

### 3.3 技术版（Hacker News / V2EX / 掘金，约 350 字）

我把 DSH 的会话投影渲染成了一张横向层级树，顺手记几个决定：

**分支判定不用余弦。** 实测真连接的余弦落在 0.29–0.72，而只共享背景词（产品名、"怎么"、文件名）的伪匹配是 0.16–0.20 —— **没有阈值能把它们分开**。换成「共享信号权重 ÷ 较小一方的信号权重」后，真连接 0.44–1.00、伪匹配 ≤0.28。信号词的定义是：会话内出现 ≤2 次，或高于该问题自身的 IDF 中位数。

**布局全部算出来，不量。** 第一版坐标来自 `getBoundingClientRect`，于是连线永远晚一帧、漏一次就整层空白。现在列 = 深度 ×（卡宽 + 列间距），行用整齐树分配：叶子按序吃掉行位，**父节点在自己子树区间里居中**。第二点是关键——按前序遍历排布会让父节点必然在所有子节点之上，每条连线都得往回折，那正是横向树不可读的原因。

**只有卡片高度是量出来的**，因为它取决于提问换行数，无法预知；而且它只影响行距，不影响列、不影响父子关系。

零依赖、零构建：`lib/client.js` 是手写的 `__ModuleLoader__.load` 懒加载 CJS 包，直接用 `React.createElement`。附带 3 道离线代码门禁 + 13 个变异用例——每个历史 bug 都会被塞回一次性副本，断言指名的那道门禁变红。**只跑绿的门禁是自我安慰。**

## 5. 分享技术细节时可直接引用的句子

写文章或回答别人提问时，这些句子已经过核对，可以直接用：

- **关于阈值**：「阈值 0.40 不是拍的，是从实测分数表里读出来的——真连接 0.44–1.00、只共享背景词的伪匹配 ≤0.28，中间是断层。」
- **关于曲线**：「连线是正交折线而不是贝塞尔：两行相同时退化成一条直线，那才是『这两张对齐』的诚实画法；曲线只会把『这条分支在哪一行拐弯』藏起来。」
- **关于总标题**：「总标题不是一轮对话：它没有模块、不可选中、不产生自己的连线，也**不占一层**——所以『分支层数 1』时它和第一层照样画出来。」
- **关于暗淡而非隐藏**：「关键词过滤让没命中的卡片变暗而不移除，因为移除会让父节点消失、让结构说谎。」
- **关于手动优先**：「自动结论是猜测，所以任何一轮都能被手动改掉；改过的一轮不会再被自动重算覆盖。」
- **关于门禁**：「3 道离线代码门禁 + 13 个变异用例：每个历史 bug 都会被塞回一次性副本，断言指名的那道门禁变红。**只跑绿的门禁是自我安慰。**」
- **关于那次装不上**：「插件一度**根本装不上**，而当时那三道门禁全绿：清单里 `id: @nydsg/dsh-mindmap` 的 `@` 没加引号——`@` 是 YAML 保留指示符，解析器拒绝整个文件、安装被回滚。门禁只解析了 `lib/`，从没读过清单。」

## 6. 禁用说法（会让自己难堪）

写文案时避开下面这些，否则一被追问就站不住：

| 别说 | 为什么 | 改成 |
|---|---|---|
| 「AI 自动理解你的对话」 | 它是词面匹配，不调模型、不语义理解 | 「按词面信号判断追问关系」 |
| 「智能聚类 / 语义聚类」 | 同上，同义改写（"怎么装插件" vs "插件如何安装"）**连不上** | 「相似提问自动续接，同义改写需手动指定」 |
| 「支持中文分词」 | `Intl.Segmenter` 会把「思维导图」切成「思维」+「导图」 | 「中文按分词器的结果做最长合并，不跨多字词」 |
| 「生成式推荐问题」 | 候选题是模板拼装 | 「候选后续提问（模板拼装）」 |
| 「实时同步云端」 | 只有 `localStorage`，按会话本地存 | 「手动连接存本地，重载后仍在」 |
| 「可视化框架 / 图形引擎」 | 没有依赖，就是 SVG 折线 + 绝对定位 | 「手写 SVG 与算出来的布局」 |
